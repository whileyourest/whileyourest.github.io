# whileyourest.github.io

The official website for **While You Rest**: https://whileyourest.github.io

Plain HTML and one stylesheet, served by GitHub Pages from `main` / root. There is no build step.

| Page | URL | File |
|---|---|---|
| Studio home | https://whileyourest.github.io/ | `index.html` |
| The Notifier | https://whileyourest.github.io/notifier/ | `notifier/index.html` |
| Privacy policy | https://whileyourest.github.io/notifier/privacy/ | `notifier/privacy/index.html` |
| Support | https://whileyourest.github.io/notifier/support/ | `notifier/support/index.html` |

A new app gets its own folder with the same three pages.

The privacy policy URL goes into the Google Play Console listing. Don't move it once it's there, and update its "Last updated" date whenever the policy text changes.
